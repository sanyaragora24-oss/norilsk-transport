# Норильский транспорт — веб-версия (PWA) для iPhone

Тестовая веб-версия для iPhone без App Store и TestFlight: открывается в Safari,
ставится значком на экран «Домой».

Что есть: карта (OpenStreetMap), 61 направление и расписание НПОПАТ — те же
данные, что в Android (`android/app/src/main/assets`), остановки, поиск,
«Рядом» по геолокации, избранное, работа без сети после первого открытия.
Нет: живых GPS-данных автобусов, будильника «скоро выходить» в фоне, пробок.

Сборка: `python3 web/build.py` → `web/dist/` (публикуется в ветку `gh-pages`).
