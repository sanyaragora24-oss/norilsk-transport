# Узелок

Второй мозг: кидаешь в него голосовые, фото, файлы и мысли — он разбирает и
возвращает в нужный момент. Два входа, одна идея.

## 1. Узелок — веб-приложение

Уже работает, ставить нечего, платить не надо, VPN не нужен.

**https://claude.ai/code/artifact/bc80beff-d38a-4803-96dd-ecb5447051f0**

Открыть на телефоне → меню браузера → «Добавить на главный экран». Дальше
запускается как обычное приложение. Записи хранятся у Claude, а не в
браузере: открыл с ноутбука — всё на месте.

Чего в нём нет: он не постучится сам в 8:30 и не принимает пересылку из
чатов одним движением. Для этого — бот.

## 2. Узелок-бот — Telegram

Живёт внутри Google Таблицы. Ни сервера, ни n8n, ни платного хостинга.

* **[docs/nastroyka.md](docs/nastroyka.md)** — пошаговая настройка, 20–30 минут
* **[bot/Kod.gs](bot/Kod.gs)** — весь бот одним файлом, вставляется целиком

Коротко: завести бота у `@BotFather` → взять бесплатный ключ в
[Google AI Studio](https://aistudio.google.com/apikey) → создать таблицу →
вставить код → подставить три значения → развернуть → запустить
`Настроить()` и `Проверка()`.

Денег не стоит нигде: и хостинг, и модель (Gemini) на бесплатных тарифах.

Что умеет:

* текст, голосовые, кружки, фото, файлы — всё в один чат;
* расшифровывает голос, читает фото словами, файлы кладёт на Google Диск;
* раскладывает по шести листам: Дела, Документы, Покупки, Идеи,
  Напоминания, Личная память;
* отвечает на вопросы словами: «что у меня на этой неделе»;
* около 8:30 сам присылает, что сегодня и что горит;
* отвечает только тебе — чужие сообщения молча выбрасываются.

Утренняя сводка собирается из таблицы без обращения к модели, поэтому
приходит даже когда модель отвалилась или кончился суточный лимит.

## Проверка логики

Разбор дат, сборка сводки и раскладка по листам покрыты тестом на моках —
запускается без Google:

```
cd bot/test && node proverka-logiki.js
```
